# mini-station-temperature-humidite
Station de mesure de température et d'humidité avec Arduino et Proteus 8.17

# Présentation :

- Ce projet consiste à réaliser une mini-station de mesure de la température et de l'humidité à l'aide d'une carte Arduino Uno. Le montage est conçu et simulé avec Proteus 8.17.

- Ce projet a été réalisé dans le cadre de mon apprentissage en première année d'Infotronique.

# Objectifs :

- Mesurer la température et l'humidité.
- Afficher les mesures sur un écran LCD .
- Allumer une LED rouge si la température dépasse 30 °C.
- Allumer une LED verte si la température est inférieure ou égale à 30 °C.

# Matériel utilisé :

- Arduino Uno
- Capteur DHT11
- Écran LCD LM016L 16x2
- LED rouge
- LED verte
- Résistances
- Potentiomètre de contraste

# Logiciels utilisés :

- Arduino IDE
- Proteus 8.17
- GitHub
  
# Fonctionnement :

- Le capteur DHT11 mesure la température et l'humidité ambiantes. La carte Arduino traite les données et affiche les valeurs sur l'écran LCD.

- La LED rouge s'allume lorsque la température dépasse 30 °C. La LED verte s'allume lorsque la température est inférieure ou égale à 30 °C.

# Fichiers du projet :

- `.ino` : code source Arduino.
- `.hex` : programme compilé utilisé dans la simulation.
- Fichier Proteus : schéma électronique du projet.
- Captures d'écran : montage et simulation.

# Compétences développées :

- Programmation Arduino en C/C++.
- Utilisation d'un capteur de température et d'humidité.
- Commande de sorties numériques.
- Affichage sur écran LCD.
- Conception et simulation de circuits électroniques avec Proteus.
- Utilisation de GitHub pour présenter un projet technique.
